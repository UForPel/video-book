# 영상책 (Video Book)

유튜브 영상을 앱 안에서 재생하면서, 영상의 자막과 정리된 글을 함께 읽을 수 있는 개인용 모바일 우선 웹앱 프로젝트입니다.

## 프로젝트 목표

- 스마트폰 브라우저에서 편하게 사용하는 개인용 웹앱
- 영상 검색과 재생, 시간대별 자막 읽기를 한 화면에서 제공
- 자막의 오탈자·띄어쓰기·문장부호를 편집해 읽기 좋은 글로 정리
- 가능하면 GitHub Pages에서 정적 웹앱으로 운영

## 개발 원칙

1. 무료 또는 거의 무료로 운영합니다.
2. 외부 유료 API와 유료 AI에 핵심 기능이 의존하지 않도록 합니다.
3. 무료 서비스라도 사용량·쿼터 제한이 있으면 핵심 의존성으로 채택하기 전에 확인합니다.
4. 가능한 작업은 서버 대신 브라우저 안에서 처리합니다.
5. Android 스마트폰에서 실제로 테스트합니다.
6. 유튜브의 공식 기능과 이용약관을 우선 검토하고, 비공식 연동은 안정성·정책 위험을 확인합니다.
7. 기존 ReadTube 프로젝트의 코드와 경험을 참고하되, 기존 저장소는 보존합니다.

## 현재 우선순위

1. 앱 안에서 유튜브 영상 검색
2. 앱 안에서 영상 재생
3. 이용 가능한 자막 가져오기
4. 자막을 시간대별로 표시하고 해당 시점으로 이동
5. 자막의 맞춤법·띄어쓰기·문장부호 편집

영상 장면 이미지 삽입, 긴 글 자동 작성, 자막 없는 영상의 음성 인식은 후속 단계로 둡니다.

## 기술적 주의사항

- GitHub Pages는 정적 파일 호스팅이며 백엔드 서버가 아닙니다.
- YouTube Data API에는 쿼터가 있으므로 사용량 제한 없는 검색 수단처럼 취급하지 않습니다.
- YouTube 공식 API는 임의의 모든 영상 자막을 자유롭게 가져오는 범용 API가 아닙니다.
- YouTube 임베드 영상의 임의 프레임을 브라우저 캔버스로 추출하는 데는 교차 출처 제한이 있습니다.
- 브라우저 내 음성 인식·AI 처리는 기기 성능과 메모리 한계를 Android에서 검증해야 합니다.
- API 키, 비밀번호, 개인 정보는 공개 저장소에 올리지 않습니다.
