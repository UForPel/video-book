# 등록 자막 파일

이 폴더에는 영상 제작자가 제공했거나 사용을 명시적으로 허가한 SRT/VTT 파일만 둡니다.

## 등록 방법

1. 허가된 자막 파일을 이 폴더에 추가합니다.
2. 저장소 루트의 `captions.json`에 YouTube 영상 ID와 파일 경로를 등록합니다.

예시 형식:

```json
{
  "abcdefghijk": "captions/abcdefghijk.vtt"
}
```

위 영상 ID와 파일명은 형식 예시일 뿐 실제 영상이나 자막을 가리키지 않습니다.

- 자막은 UTF-8 SRT 또는 WebVTT를 권장합니다.
- 영상 ID는 11자리 YouTube ID를 사용합니다.
- 실제 사용 권한이 확인되지 않은 자막은 등록하지 않습니다.
- 자막이 없는 영상은 기존처럼 사용자가 직접 SRT/VTT 파일을 선택할 수 있습니다.
